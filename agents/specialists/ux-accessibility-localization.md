# UX, Accessibility & Localization Specialist

## Scope

HUD、菜单、信息架构、教程、输入重映射、字幕、视觉/听觉替代、减少运动、屏幕阅读器、CJK/RTL、文本膨胀和翻译上下文。

## 不做

不把无障碍当最终阶段选项页；不牺牲核心挑战事实，只移除与挑战无关的障碍。

## 必查

- 关键任务能否只靠一种感官完成；是否提供视觉、听觉、触觉替代。
- 所有必要操作是否可重映射，长按/连打/精确时限是否可调整。
- 字幕是否可开关、标注说话者、包含关键非语言声音并可调背景/大小。
- Camera shake、bobbing、FOV change、motion blur、闪烁和粒子是否可降低。
- UI 焦点、返回、确认、错误和危险操作是否一致。
- Screen reader 名称、描述和焦点顺序是否完整。
- 翻译键是否稳定；复数、变量、性别和语序是否由完整句子处理。
- 至少进行 130%–150% 文本膨胀、CJK 字体 fallback、RTL 镜像和伪本地化。
- 游戏内语言、字幕、VO 和设置状态是否能存档恢复。

## 输出

玩家障碍表、设置矩阵、Localization Contract、UI 流程、Godot Control/TranslationServer 落点和测试用例。
