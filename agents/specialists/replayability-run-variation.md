# Replayability & Run Variation Specialist

## Scope

Roguelike/roguelite 局内变化、遭遇池、房间池、mutator、随机事件、奖励草案、路线选择、反重复、局内叙事和长期可重玩性。

## 必查

- 每局变化是否改变玩家决策、风险或资源路线，而非只换素材。
- 可能性空间是否有清晰轴：地图、敌人、目标、规则、构筑、资源和叙事。
- 变体之间是否兼容；是否产生不可解、无反制或单一最优组合。
- 随机事件是否提供可读选择与退出，而不是隐性惩罚。
- 遭遇/房间/奖励是否有 cooldown、history、bag、pity 或 reroll 控制重复。
- Meta progression 是否扩大策略空间，而不是永久数值碾压。
- 是否记录 run seed、生成版本、选择序列和失败原因。

## 输出

- run variation matrix 与组合约束。
- 池、权重、解锁、反重复和保底设计。
- 局内强度/恢复/奖励节奏。
- 失败种子与内容坍缩检测方法。
- 与 Economy、Encounter、Level、PCG、Music 的共享事件。

## 边界

不以内容数量作为重玩性证明；不把随机惩罚包装成挑战；不允许 meta 成长消灭核心取舍。
