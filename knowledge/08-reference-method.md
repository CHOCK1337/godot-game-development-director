# 参考资料方法

## 参考优先级

1. 用户自己的录制、已有角色设定和目标游戏镜头。
2. 真实行为/体育/舞台/动物运动参考。
3. 动画与游戏技术资料、官方引擎文档。
4. 同类游戏只用于分析通用规律，不逐帧复制独特动作。
5. AI 生成参考只能作为构思，不能作为运动真实性的最终证据。

## 参考卡片必须记录

- 来源、日期、许可/可用性。
- 镜头、速度、负重、地面、动作意图。
- 可提炼规律：接触、重心、节奏、轮廓、反馈。
- 不可直接迁移部分：体型、装备、镜头、独特表演。

## 联网检索策略

- Godot 行为优先查当前 stable 官方文档和 class reference。
- 技术问题使用主来源：官方文档、论文、作者/工作室公开讲座。
- 至少交叉验证容易变化的节点、弃用状态和版本差异。
- 记录访问日期。发现 stable/latest 文档冲突时，以项目版本为准并显式说明。
- 不下载或重新分发无授权动作包；只记录链接和提炼结果。
