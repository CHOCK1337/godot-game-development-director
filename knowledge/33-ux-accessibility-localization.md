# UX, Accessibility & Localization

无障碍是消除与核心挑战无关的障碍。关键事实不应只有颜色、声音或震动一个通道。

## Minimum matrix

- Remappable input；hold/tap/timing alternatives。
- Subtitle size/background/speaker/critical sounds。
- Reduced motion、shake、flash、particle 和 blur。
- UI focus、back/confirm、screen reader names/descriptions。
- 130–150% text expansion、CJK fallback、RTL、pseudolocalization。
- 设置持久化并可在首次进入游戏前配置。
