# 多 Agent 路由与隔离

## 独立域
动作、核心玩法、经济成长、遭遇节奏、互动配乐、Godot 音频、Godot 运行时、素材风格可在证据充分时并行分析。

## 共享依赖
- 动作承诺 ↔ 输入/反制；
- 命中 ↔ 碰撞/VFX/SFX/镜头/UI；
- 遭遇强度 ↔ 音乐状态；
- Boss 阶段 ↔ 规则/动作/场景/BGM；
- 奖励 ↔ 经济/UI/SFX/遥测。

共享依赖只能由编排器通过 Event Contract 合并，不得由两个专家各自直接修改。

## 最小派发
只派能改变最终结论的专家。无证据的“很僵”“不好玩”“音乐不对”先由单 Agent 生成采样和可证伪假设，不启动全群。
