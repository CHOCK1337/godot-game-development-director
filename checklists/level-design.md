# Level Design Checklist

## 拓扑
- [ ] 起点、目标和关键路径明确且可达。
- [ ] 每条支路提供不同风险、资源、信息或捷径。
- [ ] 门锁前置可获得，不会形成软锁。
- [ ] 回路、回退和不可逆点有明确意图。

## 可读性
- [ ] 至少两种方向信号支持关键转向：地标、轮廓、光照、声音、敌人朝向或构图。
- [ ] 战斗空间的入口、出口、掩体、落差和危险边界可读。
- [ ] 2D/3D 相机不会隐藏关键威胁或路线。

## 节奏
- [ ] 教学、练习、组合、测试和恢复有空间承载。
- [ ] 强度有峰值与恢复，不是持续上升。
- [ ] 重生/checkpoint 不迫使玩家重复无意义路程。

## 公平
- [ ] 出生到目标/资源的时间差符合设计目标。
- [ ] 不存在单一视线、单一 choke 或单一路线永久统治。
- [ ] 无障碍、移动能力和不同角色尺寸经过验证。
