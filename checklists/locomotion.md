# Locomotion 检查

## 接触
- [ ] 左右 contact 窗清楚
- [ ] 支撑期脚在世界空间稳定
- [ ] toe-off 前脚跟/脚掌按风格释放
- [ ] 斜坡、台阶和移动平台无吸地/穿地

## 重心
- [ ] 骨盆移动到支撑脚上方或符合风格化力线
- [ ] down/up 与支撑阶段一致
- [ ] 膝踝有承重与推离
- [ ] 头部不是简单跟随 root 正弦浮动

## 节奏
- [ ] 加速、巡航、减速可区分
- [ ] 左右步不因生成错误完全复制
- [ ] 循环接缝无速度突变
- [ ] 播放速度与 CharacterBody 实际速度匹配

## 方向
- [ ] 起步和停止有过渡
- [ ] 大角度转身有换脚/pivot
- [ ] strafe 的胸骨盆扭转可控
- [ ] 高速转弯有倾斜和外侧承重
