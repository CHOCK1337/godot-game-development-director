# Interactive Music Checklist

- [ ] 音乐职责明确：信息/情绪/身份/节奏/空间。
- [ ] 状态轴不超过 1–3 个且来自稳定游戏语义。
- [ ] 每个状态有 purpose、layers、BPM、meter、min hold。
- [ ] 进入/退出阈值、滞回、冷却、优先级和 fallback 完整。
- [ ] 转场指定 immediate/beat/bar/phrase/end。
- [ ] 并行 stem 共享同步基准与循环边界。
- [ ] Stinger 只用于稀有或结果性事件。
- [ ] 音乐给 SFX/Dialogue/UI 留出频谱、响度和注意力空间。
- [ ] 暂停、恢复、切场景和状态抖动已测试。
