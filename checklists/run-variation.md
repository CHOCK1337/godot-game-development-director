# Run Variation Checklist

- [ ] 每个变化轴至少改变路线、策略、风险、资源或目标之一。
- [ ] run arc 有 setup、build、peak、recovery、test 和 resolution。
- [ ] 房间/遭遇/奖励池按 slot 与兼容标签采样。
- [ ] 组合约束阻止不可解、无反制或单一最优组合。
- [ ] 使用 bag/history/cooldown/pity/reroll 控制重复与长尾。
- [ ] 随机事件提供可读选择、成本和退出，不是隐性惩罚。
- [ ] meta progression 扩大选择，不永久消灭核心取舍。
- [ ] 记录 seed、选择序列、reroll、死亡房间和生成版本。
- [ ] 检查内容曝光率、path diversity、choice rate 和 seed outliers。
