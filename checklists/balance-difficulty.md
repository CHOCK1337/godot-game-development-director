# Balance & Difficulty Checklist

- [ ] 平衡目标不是默认“所有胜率 50%”。
- [ ] 定义 novice / competent / expert 等 skill bands。
- [ ] 分开信息、决策、执行、资源、协作挑战。
- [ ] 每个 tuning parameter 有单位、默认、上下界、步长和依赖。
- [ ] 失败原因可读，玩家有至少一种反制。
- [ ] 难度曲线包含教学、练习、组合、测试和恢复。
- [ ] 报告分布和尾部，不只看平均完成率。
- [ ] 构筑/角色有策略差异，不是轻微数值差。
- [ ] DDA 使用稳定信号、滞回、冷却、最大步长和回滚。
- [ ] DDA 不暗改碰撞、命中、读招或玩家已掌握规则。
