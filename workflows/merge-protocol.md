# Merge & Conflict Protocol v5

## 证据去重
相同 source/state/range 的同义观察合并，保留来源和置信度。

## 因果合并
不投票。建立：`观察 → 假设 A/B → 验证 → 责任层 → 裁决`。

## 优先级
1. 破坏输入、接触、命中、资源权威或关键提示的错误。
2. 破坏核心决策、反制、公平和失败学习的错误。
3. 破坏 encounter/BGM 状态、转场和跨系统同步的错误。
4. 破坏风格身份与素材语义的错误。
5. 次级运动、装饰和微调。

## 共享文件与事件
专家不给共享文件直接 patch。编排器先确定 Gameplay Event Contract、owner 和 patch plan，再由一个执行者修改并运行完整验收。
