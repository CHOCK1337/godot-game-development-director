# Cross-Discipline Content Pipeline v6

1. Triage：确定体验、内容范围、证据、领域、目标设备和共享资源。
2. Production Gate：内容支柱、Must/Should/Could/Won't、Vertical Slice、最多三项 blocker。
3. 第一波并行：玩法/关卡/叙事/NPC/架构专家定义规则、状态和合同；只分析不写共享资源。
4. 合并 Quest Graph、NPC Knowledge、Gameplay Event、Save Schema、Level/Balance/Generator 和 stable IDs。
5. 第二波并行：动作、镜头、SFX/VO、音乐、UX、Asset Style、Technical Art 和 Godot 实现。
6. 主执行者按 shared-file owner 顺序修改 `.tscn/.tres/.gd/Resources`。
7. Playtest Analysis 按需分析行为和数据。
8. Content QA 执行任务软锁、NPC 状态、相机、音频、语言、存档、预算和覆盖矩阵。
9. QA Acceptance 查跨域矛盾；失败回到拥有根因的合同层，不用表现层补丁掩盖。
