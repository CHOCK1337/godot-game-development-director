# Support

This is an experimental community project and does not offer guaranteed support or response times.

## Questions

Use GitHub Discussions when enabled. Otherwise open an issue with the `question` label and include:

- the runtime and version you use
- the Godot version when relevant
- the Skill or specialist involved
- the prompt or task description
- expected and actual behavior
- a minimal reproducible example that contains no private or unlicensed material

## Bugs

Use the bug-report form. Routing bugs should include the dispatch input and selected specialists. Validator bugs should include the smallest failing JSON, YAML, CSV, or directory layout.

## Security

Do not file sensitive security details in a public issue. Follow `SECURITY.md`.

## Professional advice

The project does not provide legal, privacy, security-certification, medical-accessibility, or platform-certification advice.
